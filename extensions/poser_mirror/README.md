# 人物镜像 / 局域网投影扩展

`poser_mirror.dll` 是 Endfield Poser 的**外部可选扩展**，默认安装包不包含它；不放入该 DLL 时，Poser 的行为与上游一致。它有两种模式：

- **本地镜像**：把你的动作实时复制到一名小队队员身上。
- **局域网投影**：同一局域网内最多 4 人联机。每名其他玩家会显示在你小队的一个空闲、非操控位置上，动作实时同步。

本扩展只同步各自角色的姿态，不读取、不修改游戏与官方服务器之间的通信。使用前请阅读上游的[用户协议与免责声明](../../docs/user-agreement.md)。

## 构建与安装

```bat
build.bat -Extensions
```

这条命令会编译 `build\extensions\poser_mirror.dll`，并运行一次局域网协议自测（`net_selftest.exe`）。自测在本机 `127.0.0.1` 上模拟主机和多个加入者。

1. 本扩展需要**本分支编译的 poser.dll**。上游 poser.dll 没有扩展接口，扩展会直接跳过、不做任何事。
2. 退出游戏，把 `poser_mirror.dll` 复制到 `<游戏目录>\plugin\`。
3. 启动游戏，按 **L**，在主面板底部展开 **扩展插件 → 人物镜像 / 局域网投影**。

卸载时删除该 DLL 即可。也可以在 Applepie 管理器的 `[plugins]` 中写 `poser_mirror.dll=0` 停用。

## 局域网投影

所有玩家都需要安装本分支的 poser.dll 和 poser_mirror.dll，并且**小队里除了你操控的角色外，至少还要有一名队员**，因为其他玩家要"借用"你的队员来显示。

**主机**

1. 模式选 **局域网 · 创建主机**，状态栏会显示本机地址，例如 `192.168.1.23`。
2. 首次开启时，Windows 防火墙会询问 `Endfield.exe` 能否访问网络。请只勾选**专用网络**并允许。只有主机需要放行，加入者不需要。
3. 把本机地址告诉其他人。默认端口是 `28923`。

**加入者**

1. 模式选 **局域网 · 加入主机**。
2. 填写主机 IP，点击 **连接**。状态栏显示"已加入主机"即表示成功。

**选项**

| 选项 | 作用 |
|---|---|
| 玩家名 | 显示给其他人的名字，最长 31 字节。默认随机生成，不使用电脑名 |
| 显示位置 | **世界坐标**：其他玩家出现在他们在游戏中的实际位置，双方需要在同一张地图；**跟在我身边**：其他玩家排在你右侧，适合在不同地图时使用 |
| 缓冲延迟 | 默认 100 毫秒。画面卡顿、跳动时调高，想要更跟手时调低 |

面板会列出每名玩家对应的小队位置，以及和你的距离。可用的小队位置不够时，多出的玩家不显示。

## 结构

```
poser.dll（宿主）                          poser_mirror.dll（扩展）
  src/core/extension_host.h  C ABI          poser_mirror.cpp   模式、面板、队员分配
  src/game/puppet.h          编解码、接管     pose_buffer.h      时间戳缓冲与插值
  sdk/poser_extension.h      对外头文件       net_session.h      UDP 后台线程（收发、转发、超时）
                                            net_protocol.h     包格式与校验（纯数据）
                                            net_selftest.cpp   回环自测
```

**姿态格式**

`PoserHumanPose` 保存每根人形骨相对于"校准 T 姿"的旋转（表示在身体坐标系中），以及根位置、身体朝向和按髋高归一化的髋部位置。不同角色之间可以互相投影。

**协议**

- 基于 UDP，采用星形拓扑：主机编号 1，加入者编号 2–4，由主机转发加入者之间的数据。
- 每个姿态包约 1 KB，每秒 30 个，每名玩家约占 30 KB/s。
- 包头包含魔数、协议版本、会话号和序号。接收端会丢弃乱序和重复的包。
- 超过 5 秒没有消息，就视为对方断开，会自动重连。

**安全**

- 收到的数据按长度、会话号和来源地址校验。
- 姿态数据中的数值必须有限、四元数长度合理、骨骼掩码合法。主机和宿主各校验一次。
- 名字始终以 NUL 结尾，截断时不会切断 UTF-8 字符。

**线程**

- 网络收发只在扩展自己的后台线程中进行。
- 游戏线程只交换已经复制好的姿态数据，不等待网络。

## 许可

本扩展按 AGPL-3.0 提供。它会在网络上与其他玩家交互，因此面板中会显示源码地址（AGPL-3.0 第 13 条）。如果你修改后分发，请同样提供修改后的源码。

## 后续

1. **跨网络联机**：增加中转服务器，或者使用虚拟局域网工具（例如 ZeroTier、Tailscale）直接使用当前的局域网模式。
2. **场景校验**：宿主提供场景标识后，写进包头，不在同一地图时自动切换为"跟在我身边"。
3. **表情同步**：同步表情和视线。
