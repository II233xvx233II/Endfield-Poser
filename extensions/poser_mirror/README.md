# 人物镜像扩展（联机投影 · 第 1 步）

`poser_mirror.dll` 是 Endfield Poser 的**外部可选扩展**。它把当前操控角色的动作实时复制到一名小队队员身上，让队员像"投影"一样在你身旁同步动作。默认安装包不包含它；不放入该 DLL 时，Poser 的行为与原版完全一致。

这是联机投影的本地原型：姿态先编码成与角色无关的格式，存入带时间戳的缓冲，再插值后写到队员身上。第 2 步只需把"本地采集"换成"网络接收"。

## 构建与安装

```bat
build.bat -Extensions
```

产物在 `build\extensions\poser_mirror.dll`。使用 CMake 时加 `-DPOSER_BUILD_EXTENSIONS=ON`。

1. 本扩展需要**包含扩展接口的 poser.dll**（即同一份源码构建的版本）。旧版 poser.dll 没有 `PoserGetExtensionApi` 导出，扩展会直接跳过。
2. 退出游戏，把 `poser_mirror.dll` 复制到 `<游戏目录>\plugin\`。
3. 启动游戏，按 **L** 打开面板，在主面板底部展开 **扩展插件 → 人物镜像**。

卸载时删除该 DLL 即可。也可以在 Applepie 管理器的 `[plugins]` 中写 `poser_mirror.dll=0` 来停用。

## 使用

| 选项 | 作用 |
|---|---|
| 启用人物镜像 | 接管所选队员，开始同步；取消勾选后，队员恢复到接管前的状态 |
| 投影到 | 小队第 1–4 位。不能选当前操控角色 |
| 右侧 / 前方 / 高度 | 投影相对于你的位置，按你的朝向计算，单位为米 |
| 朝向偏移 | 让投影转向，例如 180° 表示面对面 |
| 模拟延迟 | 人为加入延迟，用来检验第 2 步网络传输的插值效果 |

单人 MMD 播放时也能镜像：投影会跟着你一起跳。

以下情况会自动恢复被接管的队员：

- 多人 MMD 播放器开始播放；
- 切换操控角色；
- 小队顺序或队员发生变化；
- 扩展出错。

步骤 1 只同步身体骨骼，不同步表情、眼睛和下巴；投影角色的武器照常显示。

## 结构

```
poser.dll（宿主）                                 poser_mirror.dll（扩展）
  src/core/extension_host.h  C ABI、回调、面板       ├─ onFrame: captureControlled → 缓冲
  src/game/puppet.h          姿态编解码、接管队员     │           → 插值 → applyPuppet
  sdk/poser_extension.h      对外头文件（唯一依赖）    └─ onGui:   通过 ui* 函数绘制设置
```

- **姿态格式** `PoserHumanPose`：保存每根人形骨相对于"校准 T 姿"的旋转（表示在身体坐标系中），以及根位置、身体朝向和按髋高归一化的髋部位置。发送端和接收端各用自己角色的 Avatar 自动校准来解码，所以不同角色之间可以互相投影。结构体大小固定、不含指针，可以直接作为网络包；宿主会校验接收到的数据（数值必须有限、四元数长度合理、掩码合法）。
- **接管队员**：复用多人播放器的保存、冻结、恢复流程（`MmdSquadCaptureActor`），会关闭动画、IK 和 LookAt 等写入组件，头发和衣物物理保持运行。
- **线程**：`onFrame` 在游戏主线程上执行，`onGui` 在 ImGui 帧内执行，宿主保证两者不会同时运行。

## 第 2 步要做的事

1. 在扩展中加入 UDP 收发：把 `captureControlled` 的结果发给对方，把收到的姿态以"接收时间"存入同一个缓冲。
2. 按网络抖动把"模拟延迟"改为自适应缓冲，比如 100–200 ms。
3. 在包头加入场景 ID 和协议版本，不在同一场景时不显示投影。

只同步你自己的视觉数据，不要读取、修改或伪造游戏与官方服务器之间的通信。
